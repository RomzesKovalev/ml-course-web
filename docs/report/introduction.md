
# Введение

## Актуальность

Машинное обучение используется во многих современных технологиях, поэтому его изучение является важной частью подготовки специалистов в области информационных технологий. Однако некоторые алгоритмы довольно сложно понять только по лекциям и учебникам. Например, при изучении градиентного спуска, линейной регрессии или метода k ближайших соседей важно видеть, как изменение параметров влияет на результат работы модели. Существуют образовательные ресурсы, такие как TensorFlow Playground, Google Machine Learning Crash Course и учебник по машинному обучению Яндекса. Они помогают изучать алгоритмы, но имеют разные возможности и не всегда соответствуют программе конкретной учебной дисциплины. Поэтому разработка русскоязычного учебного сайта, который объединяет теорию, интерактивные демонстрации и работу с собственными данными, является актуальной задачей.



## Цель проекта

Разработать веб-проект «Машинное обучение» — интерактивный учебный ресурс по одноимённой дисциплине, объединяющий теорию, интерактивные демонстрации алгоритмов и песочницу для анализа данных пользователя.



## Задачи проекта

Для достижения поставленной цели необходимо:

1. Проанализировать существующие образовательные ресурсы по машинному обучению.
2. Сформировать требования к функциональности и интерфейсу сайта.
3. Спроектировать структуру веб-приложения, базу данных и систему взаимодействия пользователей.
4. Реализовать учебные модули с теорией и интерактивными демонстрациями алгоритмов.
5. Разработать песочницу для загрузки CSV-файлов, анализа данных и обучения моделей.
6. Протестировать основные функции сайта и правильность вычислений.
7. Развернуть веб-приложение с использованием Docker и подготовить документацию.

В результате выполнения проекта планируется создать образовательный веб-ресурс, который позволит студентам изучать алгоритмы машинного обучения и закреплять полученные знания на практике.
