# ml-course-web


## Проект - Интерактивный учебный веб-ресурс по теме «Машинное обучение»

## Цель проекта
Разработать веб-проект «Машинное обучение» — интерактивный учебный ресурс по одноимённой дисциплине, объединяющий теорию, интерактивные демонстрации алгоритмов и песочницу для анализа данных пользователя.

## Технологический стек (обязателен к использованию):

– Python 3.12 — язык серверной части и расчётов;

– Django 5.2 (LTS) — веб-фреймворк; из предложенных вариантов (Django или Flask) выбран Django ради встроенной админки, через которую преподаватель ведёт материалы, готовой авторизации django.contrib.auth, ORM и миграций;

– PostgreSQL 16 — база данных;

– шаблоны Django + Bootstrap 5.3 + HTMX 2 — интерфейс; HTMX обеспечивает интерактивность (отправку значений ползунков и замену фрагмента страницы) без SPA-фреймворка;

– numpy, pandas, scikit-learn (не ниже 1.5) — вычисления, работа с таблицами, модели;

– Plotly — интерактивные графики: фигура строится в plotly.py на сервере, передаётся в браузер как JSON и отрисовывается plotly.js;

– matplotlib — статичные рисунки для теории и отчёта;

– folium — карты для кластеризации пространственных данных;

– KaTeX (допустим MathJax) — отображение формул;

– Jupyter Notebook — прототипирование расчётов перед переносом в код (папка notebooks/);

– Docker Compose + gunicorn + nginx — контейнеризация и развёртывание;

– pytest + pytest-django — автотесты;

– Git, GitHub, GitHub Projects — контроль версий и управление задачами.
Точные версии всех Python-пакетов фиксируются в requirements.txt.
